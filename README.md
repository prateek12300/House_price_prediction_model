# House_price_prediction_model
This repository contains my Course-Based Project: House Price &amp; Rent Prediction System. The project takes user inputs such as city, BHK, and property area, and predicts the estimated buying price and rent using predefined price-per-sq-ft values. It is built using Python and focuses on basic logical modelling and user-interaction design.
